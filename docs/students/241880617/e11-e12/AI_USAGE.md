# AI 使用说明（E11–E12）

记录范围：2026-11-10 至 2026-11-17，A05 组 A 轨 E11/E12 实验过程中使用 AI 助手（WorkBuddy / DeepSeek-V4.1-Flash）的实际情况。原则：AI 负责“整理命令、定位根因、起草文本”，**所有命令由本人执行、所有输出由本人回贴核验**，远程写操作（commit / push / PR）未经本人确认不执行。

## 1. 使用了什么

| 环节 | AI 参与内容 | 本人负责 |
|---|---|---|
| 环境准备 | 校验实验包 `MANIFEST.sha256.json`、发现服务器 `unzip` 会把中文目录解成 CP866、给出 `python3 -m zipfile` 与 `03_*` 通配方案 | 上传、解压、核对 `ls` 输出 |
| E11-A | 解释 `pipeline.py` 中 `check_envelope` / `normalized()` 的断言位置，判定“额外做集合比对脚本”属多余（手册只要求 `cat` 查看字段） | 执行 run、贴回 `result.json` 与 `incremental-report.json` |
| 换提交实验 | 设计 C2（改注释）/C3（加 `#include`）两个提交以对照“复用 / 刷新”，给出 `swap-c2/c3` 的请求生成脚本 | 建 `data/swap-repo`、执行两次 run、确认 `refreshed/reused` 数值 |
| E12 超时 | 从 `draft-build/iter-02/build.log` 定位到 `deb.debian.org` 9.6 MB 索引卡 148 s、耗尽 600 s，提出 TUNA 换源 + `ForceIPv4`/`Retries` + `build_timeout=1800` | 验证 TUNA 可达、改候选、重跑 |
| 真实项目接入 | 定位 `prepare_candidate` 对 pinned digest 的误判，给出 `autobuild.py` 的两行修正与 3 个测试用例 | 本地跑五种场景确认 PASS/REJECT、执行测试、拉 B1 bundle 核对哈希 |
| API 联调 | 按《02_E12接口联调.md》给出 curl 与轮询命令，解释 `curl: (23)` 是管道提前关闭而非服务端错误 | 起服务、提交、轮询、下载、核对 `ALL_EQUAL` |
| 报告文本 | 起草本目录 `个人报告.md`、`ADR.md`、`数据与联调记录.csv` 的结构与文字 | 核对每个数字与路径、判断结论是否成立 |

## 2. AI 出错并被本人纠正的地方

| # | AI 的错误 | 本人的纠正 | 最终处理 |
|---|---|---|---|
| 1 | 给的命令把 `repo` 写成宿主绝对路径（`Path('data/swap-repo').resolve()`），与手册里 `/course/...` 的容器视角不一致 | 指出“命令与手册不一致” | 改为 `/course/data/swap-repo`；`/course` 挂载路径本身手册是对的，只有候选文件与 `build_timeout` 确实需要改 |
| 2 | 在 E12 跑完后直接跳到“验证 CI”，漏掉手册 `03_真实项目接入与验收.md` | 追问“为什么就到验证CI了”“你是不是又在乱跳” | 承认跳步，按 01→02→03→04 重新排剩余清单，补做真实项目五阶段 |
| 3 | 把聊天客户端对 `@//data` 的 mention 渲染误判成命令笔误，要求改路径 | 指出那是渲染不是输入 | 撤销该误判，保留原命令 |
| 4 | 建议额外写一段“增量 vs 全量”集合比对脚本作为证据 | 质疑该段在手册里没有 | 承认属多余：`pipeline.py` 已用 `normalized()` 强制比较，退出码 0 即判据 |

## 3. 由本人判断、AI 未参与的部分

- 组内分工与边界：本人只承担 E11-A 与真实项目五阶段，B1 检测结果（241880353）与最终 CI/PR（241880106）不由本人替代。
- 是否清除既有工作痕迹：判为不清除，`work/` 里失败运行（`swap-c2/c3`）保留为失败证据。
- 所有“结论句”（例如“复用粒度是整项目 key”）都以本人执行后的实测字段为准，AI 只做归纳。
- 提交信息的措辞、PR 的 base 分支选择（`e11-e12-integration` 而非 `main`）由本人决定。

## 4. 未使用 AI 的部分

- 未让 AI 直接操作服务器（本机到服务器的 SSH 密钥此前已按本人要求撤销），AI 只输出命令文本。
- 未让 AI 代为 commit / push / 创建 PR，这三步由本人执行并在 PR 页留痕。
