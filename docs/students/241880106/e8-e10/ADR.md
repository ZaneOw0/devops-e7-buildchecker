# 决策记录：依赖图复用与失效

## 背景与选择

沿用课程参考实现的保守失效策略：以本地 C/头文件预处理指令、Make 配方、CFLAGS 和编译器身份构建缓存 key。key 未变时复用实际图；key 改变时刷新两个对象目标。每次仍重新读取当前 Make 声明并计算 MD/RD。

## 代价与范围

这一策略覆盖本次受限 C/Make 样例，代价是一个头文件变化也会刷新两个目标。更细粒度的受影响目标分析需要额外维护映射，并用全量图验证无漏边，本轮未修改参考算法。

## 验证

E8 间接包含与 E9 添加/删除包含均验证刷新及发现变化；E10 六类各五次比较完整 actual、declared、findings，个人两层间接包含额外五次。动态 BuildChecker 证据和路径见个人报告。
